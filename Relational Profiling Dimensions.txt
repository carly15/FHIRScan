┌─────────────────────────────────────────────────────────────────────────┐
│                     RELATIONAL PROFILING DIMENSIONS                      │
└─────────────────────────────────────────────────────────────────────────┘

1. CARDINALITY PER ANCHOR
   ├── Resources per Patient (e.g., 15 Observations per Patient on average)
   ├── Resources per Encounter
   └── Encounters per Patient

2. REFERENCE INTEGRITY
   ├── Orphan resources (reference non-existent targets)
   ├── Missing references (required refs that are empty)
   └── Reference target distribution

3. TEMPORAL DEPTH
   ├── Date range per Patient
   ├── Encounter duration statistics
   └── Time between related events

4. STRUCTURAL DEPTH
   ├── Path depth per resource type
   ├── Array cardinality (e.g., how many diagnoses per Encounter)
   └── Extension usage patterns

5. COMPLETENESS PATTERNS
   ├── Field co-occurrence (if A present, is B also present?)
   ├── Patients with complete vs sparse records
   └── Data density scoring
